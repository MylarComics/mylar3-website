# Base requirements

Mylar3 requires:

- a computer
- [Python](https://www.python.org)
    - Minimum version: **3.8.1**
    - Recommended version: **3.11.4**
- unrar (linux/macOS/Windows) or winrar (windows with the `Install in PATH` option or manually added post winrar install) 
- an API key from [ComicVine](https://comicvine.gamespot.com/api) or use the [Titor Cache](cv_cache)

- Alternately `Docker` and `Docker Compose (recommended not required)` 

We're aware that the Python version is now getting quite old, and work is ongoing to bump up the version support.  This will be done alongside a release announcement.
